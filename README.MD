# DevOps 2026 — Practical Exercises

This repository contains DevOps practical exercises covering containerization, Kubernetes orchestration, CI/CD automation, application security, and real-time monitoring.

## 📚 Exercises Overview

| Exercise | Topic | Description |
|---|---|---|
| [Exercise 1](./exercise1/) | Hello Pod | Deploy and run an Nginx Pod using Kubernetes and Minikube. |
| [Exercise 2](./exercise2/) | Flask on Kubernetes | Deploy a Python Flask application on Minikube. |
| [Exercise 3](./exercise3/) | ReplicaSet | Deploy and manage multiple Flask application replicas. |
| [Exercise 4](./exercise4/) | Docker Networking | Explore multi-container networking and Flask, MySQL, and Redis integration. |
| [Exercise 5](./exercise5/) | Docker Security with AppArmor | Containerize a Flask application and explore AppArmor security with the Docker SDK for Python. |
| [Exercise 6](./exercise6/) | Real-Time Monitoring and Alerting | Monitor simulated delivery metrics using Python, Prometheus, Grafana, Docker, and Jenkins. |
| [Exercise 8](./exercise8/) | Jenkins Freestyle Job | Create and execute a basic Jenkins Freestyle job. |
| [Exercise 9](./exercise9/) | Jenkins Multi-Stage Pipeline | Automate Python Flask dependency installation, code quality checks, testing, and deployment using Jenkins. |
| [Exercise 10](./exercise10/) | Multi-Node Kubernetes Deployment | Deploy Product Catalog and Shopping Cart applications with multiple replicas and pod anti-affinity. |

## 🛠️ Technologies Used

- **Containerization:** Docker, Docker Compose
- **Orchestration:** Kubernetes, Minikube
- **CI/CD:** Jenkins, Jenkins Pipelines
- **Programming:** Python, Flask
- **Monitoring:** Prometheus, Grafana
- **Security:** AppArmor, Docker SDK for Python
- **Databases and Networking:** MySQL, Redis, Docker networking
- **Version Control:** Git and GitHub

## 🎯 Learning Objectives

- Build and run containerized applications.
- Deploy applications and manage replicas using Kubernetes.
- Configure multi-node clusters and Kubernetes services.
- Automate build, test, and deployment workflows using Jenkins.
- Explore container security using AppArmor.
- Monitor application metrics and configure alert rules using Prometheus and Grafana.
- Practice version control and collaborative development workflows using GitHub.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/shreeyajas799-gif/DEVOPS_2026.git
   ```

2. Navigate to the required exercise directory:

   ```bash
   cd DEVOPS_2026/exercise1
   ```

3. Follow the instructions in that exercise's `README.md`, if available.
4. Ensure the required tools are installed before running the exercise.
